## Задача 2

### Текст задачи
Человек.
Создайте сущность Человек, которая описывается:
• Имя: строка
• Рост: целое число
Может возвращать текстовое представление вида Name, рост: height, где Name и height это переменная с именем и ростом.
Необходимо создать и вывести на экран следующих людей:
• Человек с именем Клеопатра и ростом 152
• Человек с именем Пушкин и ростом 167
• Человек с именем Владимир и ростом 189

### Алгоритм решения
Создать класс People с двумя приватными полями: name (строка) и height (целое число). Реализовать конструктор с двумя параметрами, свойства Name и Height с проверками в сеттерах (имя не пустое, рост в допустимых пределах). Переопределить метод ToString() для формирования строки вида «Человек с именем … и ростом …». В методе Main сначала запросить у пользователя количество создаваемых людей, затем в цикле для каждого человека ввести имя и рост (рост — с проверкой диапазона от 66 до 271), создать объект People и сохранить его в массив. После ввода вывести все объекты на экран вторым циклом.

## Задача 3

### Текст задачи
Имена.
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например Иванов Иван Иванович). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. Необходимо создать следующие имена:
• Клеопатра
• Пушкин Александр Сергеевич
• Маяковский Владимир
Обратите внимание, что при выводе на экран, не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения
Создать класс FullName с тремя приватными полями: surname, name, patronymic. Реализовать три конструктора: с одним личным именем, с фамилией и именем, со всеми тремя параметрами. В каждом конструкторе незаданные параметры инициализировать пустой строкой. Переопределить ToString(): последовательно добавлять в результат непустые поля, разделяя их пробелом. В Main запросить у пользователя количество имён, для каждого в отдельности запросить фамилию, личное имя и отчество (любое из полей можно пропустить нажатием Enter; при этом хотя бы одно поле должно быть заполнено — иначе запрос повторяется). Объект создаётся через универсальный трёхпараметрный конструктор FullName(s, n, p).

# Задание 2

## Задача 4

### Текст задачи
Сотрудники и отделы.
Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: Имя работает в отделе Название, начальник которого Имя. В случае если сотрудник является руководителем отдела, то текстовая форма должна быть Имя начальник отдела Название.
Необходимо выполнить следующие задачи:
1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT.
2. Сделать Козлова начальником IT отдела.
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен оказаться один и тот же отдел и начальник).

### Алгоритм решения
Создать класс Employee с полями: name (строка), departmentName (строка), head (ссылка на Employee). Реализовать свойства с проверками. В ToString() сравнить head с текущим объектом: если совпадают — вывести «Имя начальник отдела Название», иначе — «Имя работает в отделе Название, начальник которого Имя». В Main запросить у пользователя название отдела и имя начальника, создать объект начальника и присвоить ему самого себя в качестве head. Затем запросить количество сотрудников и в цикле для каждого ввести имя, создать объект Employee в этом же отделе и назначить ему того же начальника. После ввода вывести всех сотрудников циклом.

## Задача 5

### Текст задачи
Создайте сущность Пистолет (Gun), которая:
• Имеет количество патронов (целое число).
• Может быть создан с указанием начального количества патронов.
• Может быть создан без указания количества — тогда изначально 5 патронов.
• Может Стрелять: если патронов больше нуля — выводится Бах! и количество уменьшается на один, иначе — Клац!.
Создать пистолет с тремя патронами и выстрелить из него пять раз.

### Алгоритм решения
Создать класс Gun с приватным полем bullets. Реализовать два конструктора: без параметров (bullets = 5) и с параметром. Реализовать метод Shoot(): при bullets > 0 вывести «Бах!» и уменьшить bullets, иначе вывести «Клац!». В Main запросить у пользователя начальное количество патронов и количество выстрелов (оба значения — неотрицательные целые, ввод проверяется через Validating). Создать объект Gun с указанным количеством патронов и вызвать Shoot() нужное число раз в цикле.
