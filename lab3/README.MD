# Задание 1

### Текст задачи
Создать класс, содержащий единственное поле – двумерный массив. 
Реализовать три конструктора:
1. Первый массив размерностью `n x m` заполняется данными, вводимыми с клавиатуры.
2. Второй массив размерностью `n x n` заполняется случайными числами (ниже главной диагонали от -70 до 150, на главной и выше от 17 до 170).
3. Третий массив размерностью `n x n` заполняется простыми числами по спирали (ромбом), как показано в методичке.
Переопределить метод `ToString()` для вывода массива в виде таблицы.

### Алгоритм решения
Создан класс `Matrix` с приватным полем `_data`. Реализованы три конструктора для каждого типа заполнения. Для третьего массива написан вспомогательный метод `IsPrime` (проверка на простое число) и алгоритм заполнения ромба от краев к центру. Вывод матрицы реализован в переопределенном методе `ToString()`.

# Задание 2

### Текст задачи
В двумерном массиве `n x n` выберите такую диагональ, параллельную главной, сумма элементов которой была бы максимальной.

### Алгоритм решения
В класс `Matrix` добавлен метод `FindMaxDiagonalSum`. С помощью цикла перебираются все возможные смещения диагоналей относительно главной (от `-(n-1)` до `n-1`). Для каждой диагонали считается сумма, и если она больше максимальной найденной ранее, она запоминается.

# Задание 4

### Текст задачи
Из исходного бинарного файла получить новый файл, исключив повторные вхождения чисел. Исходный файл заполнить случайными данными.

### Алгоритм решения
В классе `FileTasks` реализован метод `FillBinaryFile` для генерации и записи случайных чисел. Метод `RemoveDuplicates` считывает массив чисел, проверяет каждое новое число на наличие в предыдущих элементах с помощью вложенного цикла, и записывает в новый файл только уникальные.
